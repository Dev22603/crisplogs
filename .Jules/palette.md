## 2026-06-13 - [Use rounded box corners instead of square corners]
**Learning:** Terminal log outputs looking square (`┌`, `┐`, `└`, `┘`) can feel outdated and rigid. Using rounded box characters (`╭`, `╮`, `╰`, `╯`) provides a softer, more modern interface that feels slightly more pleasant to look at.
**Action:** Default to using rounded box-drawing characters for any text-based UI borders to provide a modern and pleasant UX.
