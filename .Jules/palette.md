## 2024-06-12 - Rounded Corners for Box Drawing
**Learning:** Replacing sharp square corners (`┌`, `┐`, `└`, `┘`) with rounded box-drawing characters (`╭`, `╮`, `╰`, `╯`) provides a softer, more modern UI aesthetic for terminal logs without adding complex rendering logic or dependencies.
**Action:** When designing terminal or text-based UI, prefer rounded unicode corners over square ones for a more visually pleasant and modern feel.
