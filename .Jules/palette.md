## 2024-05-18 - Use rounded box characters\n**Learning:** The terminal log formatter uses rounded box characters (e.g., `\\u256d`, `\\u256e`, `\\u2570`, `\\u256f`) instead of square ones for boxed output styles to provide a softer, more modern UI. This makes logs more pleasant to read without reducing their structured information.\n**Action:** Use rounded corners for UI elements instead of sharp corners to provide a friendlier experience.
