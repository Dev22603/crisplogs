## 2024-06-19 - Use rounded corners for terminal box output to soften the UI
**Learning:** Terminal user interfaces with square corners can appear sharp and outdated. Softening the corners using Unicode rounded box-drawing characters (e.g., `\u256d`, `\u256e`, `\u2570`, `\u256f`) significantly modernizes the look and makes log reading slightly more pleasant.
**Action:** When designing terminal interfaces, consider using rounded corners to provide a more approachable, polished UX.
