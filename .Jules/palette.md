## 2025-07-01 - Rounded Corners for Box Styles
**Learning:** Hard, square corners in CLI UIs can feel rigid. Rounded corners (`╭`, `╮`, `╰`, `╯`) provide a softer, more modern aesthetic that feels more approachable and pleasant for users reading logs.
**Action:** Default to rounded box-drawing characters for boxed layouts in terminal UIs to improve visual polish and delight.
