## 2025-02-12 - Rounded Corners for Terminal Log Boxes
**Learning:** Hard right-angle brackets (`┌`, `┐`, `└`, `┘`) can feel a bit brutalist in modern terminal UIs. Substituting them with rounded corner box drawing characters (`╭`, `╮`, `╰`, `╯`) provides a softer, more modern and accessible aesthetic to text-based log boxes.
**Action:** When drawing terminal borders or UIs, prefer rounded corners to make the application look more modern and friendly, provided the host environment supports these Unicode characters.
