## 2025-05-18 - Rounded Corners in Terminal Output
**Learning:** Hard-angled (square) box-drawing characters in terminal applications can feel abrasive or outdated. Switching to rounded box-drawing characters (`╭`, `╮`, `╰`, `╯`) provides a softer, more modern UI aesthetic that many users find more pleasant to read, especially in information-dense logs.
**Action:** When designing or refactoring CLI tools or terminal outputs that use box-drawing elements, default to using rounded characters to enhance visual polish and user delight.
