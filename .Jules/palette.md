## 2026-06-06 - Terminal UI Softness
**Learning:** Hard angles and square corners in terminal output (like ┌, ┐, └, ┘) can feel rigid and slightly dated. Switching to rounded corners (╭, ╮, ╰, ╯) provides a softer, more modern interface that feels slightly more approachable to users when presenting structured logging information.
**Action:** When creating boxed terminal UIs or logging formats, default to rounded box-drawing characters to provide a modern, softer aesthetic.
