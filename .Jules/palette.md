## 2024-05-24 - Terminal Output UI Modernization
**Learning:** Terminal outputs can feel harsh with traditional square box-drawing characters. Rounded box characters (\u256d, \u256e, \u2570, \u256f) provide a softer, more modern UI that makes the console interface more pleasant to read.
**Action:** Use rounded box-drawing characters by default for CLI tools that use boxed output styles.
