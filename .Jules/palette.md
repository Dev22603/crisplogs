## 2026-06-07 - Use rounded box characters for a softer UI
**Learning:** Using rounded box-drawing characters (╭, ╮, ╰, ╯) instead of square ones (┌, ┐, └, ┘) in terminal UIs provides a softer, more modern aesthetic that makes logs feel less harsh and easier on the eyes.
**Action:** When designing or updating CLI tools with boxed output styles, default to rounded corners to improve the visual experience.
