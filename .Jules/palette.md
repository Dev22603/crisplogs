## 2025-06-18 - Rounded Box Corners
**Learning:** Using rounded box-drawing characters (╭, ╮, ╰, ╯) instead of square ones (┌, ┐, └, ┘) in terminal output provides a softer, more modern UI that feels less rigid and more accessible to users.
**Action:** Default to rounded corners for all newly introduced box-style terminal interfaces to maintain this softer aesthetic.
