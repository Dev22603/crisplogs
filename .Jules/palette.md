## 2025-09-08 - Use Rounded Corners for Terminal Boxes
**Learning:** Terminal outputs typically use harsh, square box-drawing characters (`┌`, `┐`, `└`, `┘`). Replacing them with rounded box-drawing characters (`╭`, `╮`, `╰`, `╯`) significantly softens the UI and provides a more modern aesthetic without requiring any functional changes.
**Action:** When designing or enhancing CLI tools and terminal applications that use boxed layouts, default to using rounded box-drawing characters for improved visual appeal and a friendlier UX.
