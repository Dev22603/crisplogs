## 2026-06-01 - Rounded Terminal Boxes
**Learning:** Using rounded box drawing characters (╭, ╮, ╰, ╯) instead of sharp ones (┌, ┐, └, ┘) in terminal logs provides a softer, more modern and delightful UX without altering the layout structure or requiring additional dependencies.
**Action:** Default to rounded corners for purely decorative CLI frames when building UI components in the terminal.
