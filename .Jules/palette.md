## 2025-06-05 - Rounded Box Drawing Characters

**Learning:** Terminal user interfaces (TUIs) can feel rigid and harsh when using sharp right angles for boxes and borders (`┌`, `┐`, `└`, `┘`). Substituting these with rounded corner characters (`╭`, `╮`, `╰`, `╯`) provides a softer, more modern aesthetic that significantly improves the visual pleasantness and approachability of the logs, bringing terminal output closer to modern web/desktop design paradigms without any new dependencies.

**Action:** When working on CLI apps or text-based UI logging that uses box drawing characters, default to rounded corners instead of sharp angles for a more polished and professional UX.
