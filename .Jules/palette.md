## 2025-06-26 - Box-Drawing Rounded Corners
**Learning:** Using rounded box-drawing characters (`╭`, `╮`, `╰`, `╯`) instead of square ones (`┌`, `┐`, `└`, `┘`) in terminal outputs creates a softer, more modern and pleasing user interface for CLI tools.
**Action:** Default to using rounded characters for boxed UI elements in terminal interfaces unless there's a strict requirement for a retro/sharp style.
