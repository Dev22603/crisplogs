## 2024-05-24 - Rounded Corners in Terminal UI
**Learning:** Terminal users appreciate the softer, more modern aesthetic of rounded box-drawing characters (`\u256d`, `\u256e`, `\u2570`, `\u256f`) over traditional harsh square corners. It makes CLI tools feel more like native modern apps.
**Action:** Use rounded corners as the default for all box decorations in terminal UIs to provide a more pleasant user experience.
