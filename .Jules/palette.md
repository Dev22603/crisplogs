## 2026-06-17 - Soften Terminal UI with Rounded Corners
**Learning:** Terminal output using sharp/square box-drawing characters (┌, ┐, └, ┘) can feel visually harsh and dated. Softening these borders with rounded characters (╭, ╮, ╰, ╯) provides a more modern, approachable UI that improves readability and aesthetic appeal, even in text-based environments.
**Action:** Default to rounded box-drawing characters for CLI and terminal output designs to create a more polished and pleasant user experience.
