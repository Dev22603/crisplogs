## 2025-06-27 - Soften Box Corners for Modern UI

**Learning:** Terminal box styles often default to harsh, square corners (┌ ┐ └ ┘) which look dated. Replacing these with rounded corners (╭ ╮ ╰ ╯) significantly softens the visual output, making log reading feel more like a modern UI experience.
**Action:** Always consider rounded characters for bordered UI elements in the terminal when building developer tools.
