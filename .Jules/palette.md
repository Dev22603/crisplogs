## 2024-05-18 - Rounded Terminal Boxes
**Learning:** Hard, square corners (┌, ┐) in terminal output can feel rigid and legacy. Using rounded corners (╭, ╮) provides a softer, more modern UI aesthetic that users perceive as more friendly and contemporary, even in CLI environments.
**Action:** When designing terminal output or CLI interfaces, default to rounded box-drawing characters for borders and containers to improve the visual polish and perceived modernity of the tool.
