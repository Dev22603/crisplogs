## 2026-06-15 - Rounded Box Characters for Terminal UI
**Learning:** Using rounded box-drawing characters (`╭`, `╮`, `╰`, `╯`) instead of square ones (`┌`, `┐`, `└`, `┘`) in terminal UIs provides a softer, more modern aesthetic that feels significantly more polished and pleasant to interact with.
**Action:** When creating text-based interfaces or log formatting, default to rounded corners to subtly improve the user experience.
